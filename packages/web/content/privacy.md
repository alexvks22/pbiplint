# Πολιτική Ασφαλείας & Ιδιωτικότητας

Το **Data Tutor · Power BI Checker** ελέγχει το Power BI project σας εκεί ακριβώς όπου βρίσκεται: **μέσα στην καρτέλα του browser σας**. Κανένα αρχείο, κανένα όνομα πίνακα και κανένα δεδομένο δεν αποστέλλεται σε εξωτερικό server.

<h2 id="the-promise">Η Δέσμευσή μας για τα Δεδομένα σας</h2>

1. **Τίποτα δεν φεύγει από τον υπολογιστή σας.** Όλη η ανάλυση εκτελείται τοπικά στον browser σας. Η εφαρμογή δεν πραγματοποιεί καμία δικτυακή κλήση (upload) κατά τη διάρκεια ή μετά τον έλεγχο.
2. **Δεν ανοίγει τα δεδομένα σας.** Το εργαλείο διαβάζει μόνο τα αρχεία δομής (metadata) του μοντέλου και της αναφοράς (`.tmdl`, `.json`, `.pbip`). Δεν ανοίγει ποτέ τον φάκελο `.pbi` (όπου αποθηκεύονται τα φορτωμένα δεδομένα σας) και δεν συνδέεται ποτέ σε βάσεις δεδομένων ή στο Power BI Service.\*
3. **Χωρίς λογαριασμούς, cookies ή tracking.** Δεν υπάρχει server που να επεξεργάζεται τα αρχεία σας. Η σελίδα αποτελείται αποκλειστικά από στατικά αρχεία και δεν αποθηκεύει απολύτως τίποτα (ούτε cookies, ούτε ιστορικό) στον browser σας.
4. **Μπορείτε να το ελέγξετε μόνοι σας.** Ο κώδικας είναι ανοιχτός και μπορείτε να επαληθεύσετε ανά πάσα στιγμή ότι δεν στέλνει δεδομένα στο internet.

\* *Σημείωση: Τα αρχεία δομής ενός Power BI project περιέχουν από τη φύση τους τα ονόματα των πινάκων, των στηλών και των measures σας, τους τύπους DAX/Power Query, καθώς και τυχόν τιμές που έχετε ορίσει σε φίλτρα ή τίτλους γραφημάτων. Το εργαλείο τα διαβάζει τοπικά για να τα ελέγξει, χωρίς ποτέ να τα αποθηκεύει ή να τα στέλνει εκτός του υπολογιστή σας.*

## Τι ακριβώς διαβάζει στον browser

Όταν επιλέγετε ή σύρετε τον φάκελο ενός έργου, η σελίδα διαβάζει αποκλειστικά:
- Τα αρχεία `.tmdl` (δομή μοντέλου, σχέσεις, measures, Power Query).
- Τα αρχεία `.json` της αναφοράς (σελίδες, γραφήματα, φίλτρα).
- Τα βασικά αρχεία του project (`.pbip`, `definition.pbir`, `.platform`).

Όλα τα υπόλοιπα αρχεία στον φάκελο παραμένουν κλειστά. Τα αποτελέσματα του ελέγχου δημιουργούνται στην οθόνη σας και, αν επιλέξετε να τα εξάγετε, αποθηκεύονται απευθείας στις Λήψεις (Downloads) του υπολογιστή σας.

<h2 id="check">Πώς να το επαληθεύσετε μόνοι σας</h2>

Αν εργάζεστε σε εταιρικό περιβάλλον και θέλετε να βεβαιωθείτε για την ασφάλεια των εταιρικών σας αρχείων:

1. **Δοκιμάστε το χωρίς internet (Offline):** Αφού φορτώσει η σελίδα, απενεργοποιήστε το Wi-Fi ή ενεργοποιήστε τη λειτουργία πτήσης. Σύρετε ένα Power BI project — ο έλεγχος θα λειτουργήσει κανονικά, αποδεικνύοντας ότι δεν απαιτείται σύνδεση στο internet.
2. **Ελέγξτε την κίνηση δικτύου (Network Tab):** Ανοίξτε τα Developer Tools του browser (`F12` > καρτέλα **Network**) και τρέξτε έναν έλεγχο. Θα δείτε ότι δεν πραγματοποιείται καμία απολύτως αποστολή δεδομένων.
3. **Αυστηρή Πολιτική Ασφαλείας (CSP):** Κάθε σελίδα διαθέτει ενσωματωμένο κανόνα ασφαλείας `Content-Security-Policy: connect-src 'none'`, ο οποίος απαγορεύει στον ίδιο τον browser να ανοίξει οποιαδήποτε σύνδεση δικτύου.
